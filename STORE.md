# Publishing to Google Play

The Android app is the same web app, wrapped with [Capacitor](https://capacitorjs.com). Everything runs on the phone: Stockfish, storage, analysis.

## 1. Tools (once)

On Omarchy:

```bash
omarchy pkg add jdk21-openjdk
omarchy pkg aur add android-sdk-cmdline-tools-latest android-sdk-platform-tools android-sdk-build-tools android-platform-36
yes | sudo /opt/android-sdk/cmdline-tools/latest/bin/sdkmanager --licenses
```

Then tell the build where the SDK is:

```bash
echo "sdk.dir=/opt/android-sdk" > android/local.properties
```

All modules are pinned to build-tools `37.0.0` (what the AUR package installs) in `android/build.gradle`, so Gradle never tries to download another version. If a Gradle download times out, retry with `GRADLE_OPTS="-Djava.net.preferIPv4Stack=true"`.

## 2. Upload key (once, keep it safe)

Google Play signs the app it ships to users. You sign your uploads with an **upload key**:

```bash
mkdir -p ~/.android-keys
keytool -genkeypair -v -keystore ~/.android-keys/chess-coach-upload.jks \
  -alias upload -keyalg RSA -keysize 2048 -validity 10000
```

Already done on this machine: the key is `~/.android-keys/chess-coach-upload.jks`, its passwords are in `~/.android-keys/chess-coach-keystore.properties`, and `android/keystore.properties` is a symlink to that file. To set it up elsewhere, create `android/keystore.properties` (it's in `.gitignore`; never commit it):

```properties
storeFile=/home/YOU/.android-keys/chess-coach-upload.jks
storePassword=...
keyAlias=upload
keyPassword=...
```

**Back up the `.jks` file and the passwords** (password manager plus an offline copy). If you lose them you can ask Google to reset the upload key, but that takes days.

## 3. Build

```bash
npm run android:bundle   # → android/app/build/outputs/bundle/release/app-release.aab  (upload this)
npm run android:apk      # → android/app/build/outputs/apk/debug/app-debug.apk        (to try on your phone)
adb install -r android/app/build/outputs/apk/debug/app-debug.apk
```

For every update, bump `versionCode` (by 1) and `versionName` in `android/app/build.gradle`.

## 4. Play Console

1. Create a developer account at https://play.google.com/console ($25 one-off, identity verification).
2. **Create app**: name *Chess Coach: Learn From Games*, App, Free.
3. **New personal accounts must run a closed test first**: at least **12 testers opted in for 14 days in a row** before you can publish to production. Create a *Closed testing* track, upload the `.aab`, add testers' Google emails, and share the opt-in link.
4. **Store listing**: copy from `store/listing.md`; graphics in `store/` (icon 512, feature graphic, screenshots).
5. **Privacy policy URL**: `https://github.com/galawaydude/chess-coach/blob/main/PRIVACY.md`
6. **App content**:
   - Ads: *No ads*.
   - App access: *All functionality available without special access*.
   - Content rating: fill in the questionnaire (no violence, no user interaction, no purchases).
   - Target audience: 13+ is simplest.
   - **Data safety**: the app has no server and no analytics. The only thing that leaves the phone is the chess.com username you type, sent directly to chess.com's public API at your request to download public games. The developer never receives it. Answering *"No data collected"* matches Google's definitions (data sent to a third party at the user's direct request, not collected by the developer), and *"Data is encrypted in transit": yes* (HTTPS). Read the questions yourself and answer honestly; you're the one declaring it.
7. After the 14-day closed test: **Production → Create release**, upload the same or a newer `.aab`, then roll out.
